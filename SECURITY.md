# Security

If you discover a security issue in this repository (for example, unsafe defaults that should be documented, or a vulnerability in how the stack is wired), please report it responsibly.

**How to report**

- Open an issue on this repository with details (omit production secrets), or
- If you prefer a private channel, contact the repository maintainer directly if they have published contact information on their GitHub profile.

This project ships a demo-oriented Grafana password by default. Change it before exposing the stack to untrusted networks. See the README production checklist.
